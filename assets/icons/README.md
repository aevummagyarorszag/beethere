# Category and featured icons

culture.svg, party.svg, fire.svg, sport.svg, gastro.svg, and romance.svg are Microsoft Fluent Emoji Color artwork (MIT): https://github.com/microsoft/fluentui-emoji . The corresponding upstream names are Performing arts, Party popper, Fire, Basketball, Shrimp, and Rose. See LICENSE-fluent-emoji.txt.

family.svg is a custom vector reconstruction of the user-supplied family reference.

All ten are genuine SVG vector artwork; no embedded bitmap or remote runtime dependency. preview.html shows the assets at 128px and 24px.

paid.svg and calendar.svg are Microsoft Fluent Emoji Color artwork (Dollar banknote and Spiral calendar); ticket.svg is Fluent Emoji Flat artwork (Wrapped gift), used for free events. The same MIT license applies.

calendar.svg has been modified to replace the spiral rings with two shaded binding tabs matching the supplied reference.
